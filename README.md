# F1 ENTRY
### Sistema de gestión y venta de entradas de Fórmula 1

**Descripción del proyecto**

F1 Entry es una aplicación web desarrollada para facilitar la consulta, reserva, compra y administración de entradas y control de aforo para circuitos de Fórmula 1

**Tecnologías utilizadas**
- Java
- Spring Boot
- MySQL
- HTML5
- Bootstrap 5
- Maven

**Funcionalidades principales**
- Catálogo de circuitos y zonas de visualización.
- Consulta de disponibilidad y precios por circuito y tribuna.
- Reserva y compra de entradas en línea.
- Validación de aforo en tiempo real.
- Consulta, actualización y cancelación de reservas por documento del espectador.
- Panel de administración protegido para organizadores.
- Telemetría de capacidad, inscritos y dinero recaudado por zona.
- Gestión de espectadores con filtros por circuito, estado y búsqueda.
- Generación y descarga de reportes en formato PDF

**Base de datos**

El proyecto incluye el archivo `f1entry.sql`, que contiene la estructura de la base de datos y los datos iniciales de los circuitos y zonas

**Ejecución del proyecto**

1. Instalar Java y MySQL.
2. Crear o importar la base de datos utilizando `f1entry.sql`
3. Configurar las credenciales de conexión a MySQL en `application.properties`
4. Abrir el proyecto con Visual Studio Code o un entorno compatible con Maven
5. Ejecutar la aplicación Spring Boot
6. Abrir la aplicación desde el navegador mediante `http://localhost:8080`
